# Academic Contents

Academic Contents is a web application for students and faculty to access and manage academic resources.

## Features

- Student Login and Registration
- Faculty Login and Registration
- Academic content by regulation
- Subject-wise content
- PDF upload and viewing
- PDF download
- Easy navigation for students and faculty

## Technologies Used

- React
- TypeScript
- Vite
- Tailwind CSS
